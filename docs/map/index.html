關於台灣所得地圖

本地圖以村里為單位，呈現財政部財政資訊中心公布的綜合所得申報統計（2011－2024）。可切換平均數、中位數、標準差與第一、三分位數等指標，點選村里可查看歷年趨勢與完整統計表。

本統計之所得為課稅資料，未納入「政府移轉支出」各戶所得、免稅所得、分離課稅所得等資料，故不宜逕作為衡量所得差距之參據，相關所得資料應以行政院主計總處公布之資料為準。
