# 台灣所得地圖 (Taiwan Income Map)

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fkiang.github.io%2Fsalary%2Fmap%2F)](https://kiang.github.io/salary/map/)

An interactive visualization project that maps income distribution across Taiwan using government tax data from 2002 to 2023.

## Overview

This project provides a geographical visualization of income distribution across different regions in Taiwan. The data is based on official tax records and is updated annually when new government data becomes available.

## Data Source

- Data is sourced from official Taiwan government tax records
- Latest data is typically released mid-year
- Note: The income data shown is based on taxable income and does not include:
  - Government transfer payments
  - Tax-exempt income
  - Separately taxed income

## Features

- Interactive map visualization
- Income data displayed in thousands of NTD
- Multiple visualization metrics:
  - Mean income
  - Median income
  - Standard deviation
  - First quartile
  - Third quartile
- Historical data from 2002-2023
- Quick region selection for major cities/counties
- Color-coded income ranges:
  - < 300k
  - 300k-400k
  - 400k-500k
  - 500k-700k
  - 700k-900k
  - 900k-1.1M
  - 1.1M-1.3M
  - 1.3M-1.5M
  - > 1.5M

## Website

Visit the live visualization at: [https://kiang.github.io/salary/map/](https://kiang.github.io/salary/map/)

## Disclaimer

The statistics shown are based on tax data and should not be used as the sole reference for income disparity analysis. For official income statistics, please refer to the data published by the Directorate General of Budget, Accounting and Statistics, Executive Yuan, R.O.C.
